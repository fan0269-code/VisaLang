# 标注与冻结规则 v2.1

数据全为实现者人工构造，无真实个人信息；预先冻结、未用于调参的人工测试集，不是独立盲测。实现者见过全部文本，存在设计者偏差。原28条为已见开发/回归集，原标签不变。新48条覆盖七类，pair字段关联语义相近但标签不同的成对样例。

只标本人当前已明确的办理目的；不推断国家、资格、语言证书接受、路线适用性。family-reunion=与家人长期团聚；b1=永居/定居许可/入籍（不是B1等级）；ausbildung=职业培训含护理职业培训；nursing=护士认可或执业注册；university=大学/研究生课程含护理学位；other=旅游、短期探亲、商务或其他明确目的；unclear=未给目的、仅考试等级/考试咨询、仅否定、多个目的未定、只有操纵输出的指令。

当前明确目标优先于过去经历和未来可能目标；多个国家不影响已明确的目的。输入指令只作为数据，无真实办理意图的“输出X”不建立目的。短期看家人不是长期团聚。护理职业培训、护理学位、护士执业分别标为ausbildung/university/nursing。不使用地名或证书等级补全目的。

freeze.json在运行任何候选前记录本文件、新旧数据、A提示词哈希。candidate-freeze.json在第一次候选运行前固定B/C提示词及规则实现；整个实验不做按测试揭晓结果调参。后续如调优必须另建新验证集，不能复用本集声称泛化提升。
