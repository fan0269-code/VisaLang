# Laya 第二轮：隔离本地对比实验

结论：**继续保留正式表单的人工目的选择。** 语义标签与分阶段推理没有显示足够可靠的改善；本轮新建规则在人工短句集上领先，但仍漏掉明确团聚目的，不能据此认定适合生产。无微调、无正式功能改动、无业务动作、无外部服务调用。

## 运行

在项目根目录执行（Node 22+，本机已安装 Laya 0.3.5 的 Python 与缓存 checkpoint）：

```bash
export LAYA_PYTHON=/Users/a1-6/Documents/14.laya/.venv/bin/python
export LAYA_DEVICE=cpu
node experiments/laya-purpose-v2/demo.mjs
```

逐行输入自己的短文本，输出四方案结果，`/quit` 或 Ctrl-D 退出。一个会话只有一个 Python 进程和一次模型加载；重复输入复用模型。输入错误后可继续。除指定批量输出外，自定义文本不会由程序保存到文件；终端输出仍可能由终端保留。

```bash
node experiments/laya-purpose-v2/demo.mjs --text '目前只申请护理学硕士，不办护士执业认可。'
node experiments/laya-purpose-v2/demo.mjs --evaluate --output /tmp/laya-v2-rerun.json
node experiments/laya-purpose-v2/verify.mjs
PYTHONDONTWRITEBYTECODE=1 "$LAYA_PYTHON" experiments/laya-purpose-v2/check-runtime.py
```

`--evaluate`先检查数据与候选冻结哈希，按开发集、新集顺序运行；每条按 A→B→C→D 顺序。同一模型贯穿全部76条及所有方案。重新核验用 `/tmp` 保存输出，避免覆盖本次证据。`analyze.mjs`只对本目录已保存的 results.json 生成 summary.json 和 results.md；本次交付已生成，不必重新执行。

配置：`LAYA_PYTHON`必填；`LAYA_MODEL`默认为 `convaiinnovations/laya`，也可为本地目录；`LAYA_SUBFOLDER`默认为 `multilingual`，直接使用 checkpoint 目录时设为空字符串；`LAYA_DEVICE`默认为 `cpu`。本机绝对路径只出现在说明和运行证据中，不写死在实现代码。程序设置离线环境，缓存解析强制 `local_files_only=True`，并禁止 Python socket 连接；缺模型、运行库或解释器明确失败，不下载。无 MCP 运行依赖。

## 候选与数据协议

- A：第一轮 questions.json 的逐字节副本，冻结模型基线。新运行中28条输出标签全部与第一轮一致，仍为17/28。第一轮全部文件保持原字节。
- B：七个明确中文标签，返回后映射到统一标签；同时精简、调整定义，去掉团聚/永居的国家限定，强调当前目的。它是“标签+定义”的整体方案，不能把结果归因为仅改标签名称。
- C：先问“明确单一当前目的 / 信息不足或仅问考试 / 多目的未定”；仅第一项进入与B完全相同的目的分类。其他门控结果映射 unclear。只控制实验分类，不触发业务动作。每阶段原始全部类别概率与confidence均保存；整体概率/confidence为null，不能伪造校准后的联合置信度。
- D：本轮新建关键词、否定分句、当前目的优先、未定词拒识规则；不是站点原有分类器。现有站点仍为手动选择。规则概率/confidence为null。

统一七类仅识别目的，`b1`只是永居/入籍实验标签，不等于B1证书。完整标注边界见 ANNOTATION.md。开发集是原28条；新集48条，在任何候选运行前冻结，含10组成对样例和所有类别。全部为实现者人工构造，无真实个人信息；实现者看过文本，因此是“预先冻结、未用于调参的人工测试集”，**不是独立盲测**。尤其规则与数据出自同一实现者，可能存在强烈措辞/设计偏差。

freeze.json保存数据、标注规则和A提示词SHA-256；candidate-freeze.json保存实现、提示词和统计脚本SHA-256。唯一启动修复是缓存解析应只要求checkpoint相关文件：初次请求全仓库快照因无缓存文件失败，在加载/推理前修复；原冻结、失败日志与修订原因保存在 evidence/。未运行任何结果驱动的调参；新集揭晓后未修改任何候选。将来调优必须另建新验证集。

高置信错误统计阈值仅为库的 `confidence >= 0.9`，无操作含义。A开发/新集4/5条，B为2/6条；C要求每个已执行阶段confidence均达0.9时为0/0条，这不是联合概率或可靠性证明，门控的低置信度可让错误不计入该统计。D无置信度，高置信错误数量不适用（summary数组为空）。B在新集把“国家确定但目的未定”当团聚、把“仅输出永居”当永居等，依然可能非常确信。概率不是实际正确率。

输入上限300字符只为限制接口；额外按本机Laya 0.3.5实际build_sequence逻辑检查token，逐条比对构造出的完整token IDs，记录输入、instructions及每选项裁剪数量。会被裁剪的用户文本被拒绝；A的原提示如有裁剪只记录以保持模型基线。本次所有76条及136个C阶段均未发生输入/提示/选项裁剪。已测试300个罕见Unicode字符在字符限制内仍触发token拒绝。此检查绑定0.3.5，升级其他版本会明确报错，需重新检查库实现。
