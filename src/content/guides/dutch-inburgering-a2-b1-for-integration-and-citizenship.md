## Start with a procedure-first route check

Do not start from “A2 or B1?” Start by naming the official task. The reviewed sources separate:

1. an integration requirement for a named more-secure residence procedure;
2. an integration requirement within a naturalisation procedure;
3. the civic-integration obligation in the Netherlands; and
4. a separate study-admissions task such as the named UvA/NT2 route.

These routes can point to related language evidence, but they do not give the same office the same job. This page remains `verification-pending` because it cannot determine an individual's applicable law, cohort, route, level, deadline, exemption, evidence acceptance, or outcome.

## Choose the authority for the task

| Authority or record | Use it for | Do not use it to decide |
|---|---|---|
| IND | The current integration requirement for a named more-secure residence procedure; the naturalisation requirements; the final residence or naturalisation decision | The personal course, PIP learning route, current exam screen, or local exam execution |
| Municipality | The naturalisation application entry point and original-evidence review; under Wi 2021, the PIP and educational route for the civic-integration obligation | An exam provider's current registration, component, or result process |
| DUO / Inburgeren | Civic-integration obligation information and the current exam product, components, registration, adjusted-exam and result workflow | Whether an IND residence or naturalisation application will succeed |
| Mijn Inburgering / PIP | The person's recorded applicable act, integration start information, educational route, required exams, and current dynamic status | A general rule for another person or a separate UvA admissions decision |

For a named residence procedure, start with the current IND procedure and ask IND which integration evidence belongs to that application. For naturalisation, start with IND, then contact the municipality where the application will be submitted so it can check the current document instruction and evidence. The municipality sends the application and advice onward; IND decides the naturalisation request.

If the task is the civic-integration obligation in the Netherlands, use Inburgeren and Mijn Inburgering. Where Wi 2021 applies, use the PIP made with the municipality to identify the educational route and required exams. Do not substitute a general overview for that personal record.

## Build a personal route record

Complete this record from the current official instruction before registering:

| Record | What to save |
|---|---|
| Named task | The exact residence permit procedure, naturalisation application, or civic-integration obligation |
| Receiving or deciding authority | IND, the naturalisation municipality, or the municipality responsible for the PIP |
| Applicable law or cohort | The entry shown in Mijn Inburgering or the current written authority instruction |
| PIP and learning route | The current PIP route if Wi 2021 applies; otherwise mark it not applicable or unresolved |
| Required components and level | Copy the current personal list from Mijn Inburgering, the PIP, or the named authority instruction |
| Deadline or dynamic status | Copy the personal date or status from the official record; do not calculate one from this page |
| Exemption or dispensation | Record only the authority's current instruction, required evidence, and unresolved questions |
| Next official contact | The office that can answer the first unresolved item |

If the named task, applicable law, or personal record is missing, stop before selecting an exam or course.

## A2/B1 stop rule

The A2 and B1 labels in search results or course marketing do not establish the rule for a person. Do not choose a level by combining a general IND page with a general DUO product page.

Proceed only when the exact procedure instruction and the personal official record identify what applies. If IND, the municipality, Mijn Inburgering, and the PIP appear inconsistent, keep the level and component list `unknown` and ask the authority responsible for the named task. Do not resolve the conflict by choosing the higher, lower, newer, or more familiar label.

## Keep Inburgering and UvA/NT2 as separate terminal tasks

This Inburgering page is for a named residence or naturalisation integration requirement, or for the civic-integration obligation and its personal route record.

The separate UvA/NT2 page is bounded to a named University of Amsterdam Dutch-taught bachelor's admissions task. It does not establish an IND requirement, civic-integration obligation, work rule, or another institution's evidence decision. Neither page is a sequential next step for the other; use the page that matches the receiving authority and stop there.

## Common mistakes

- Treating the integration requirement for a named IND procedure as identical to the civic-integration obligation in the Netherlands.
- Asking DUO or a course provider to predict a residence or naturalisation result.
- Treating a general exam list as the person's Mijn Inburgering or PIP record.
- Choosing A2 or B1 before confirming the applicable law, procedure, and personal route.
- Calculating a deadline or residence period from a summary instead of copying the current official instruction.
- Assuming a course, diploma, exemption, dispensation, or document will be accepted without the responsible authority's check.
- Moving from Inburgering to NT2 because both concern Dutch, even though the receiving authority and task are different.

## Next action

Choose one named task only. Open the responsible official source, fill every row of the personal route record, and send the first unresolved question to IND, the naturalisation municipality, DUO, or the municipality responsible for the PIP.

Stop when that record is saved. Do not continue to the UvA/NT2 page unless a separate, named UvA Dutch-taught bachelor's admissions task applies.
