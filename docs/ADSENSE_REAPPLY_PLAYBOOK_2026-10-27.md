# AdSense 重申作战手册（2026-10-27）

> 适用范围：VisaLang（visalang.org）因"低价值内容（Low value content）"被拒后的二次申请。
> 本手册只做合规改进，不包含任何绕过审核的手段。

## 一、先确认一件事

AdSense 的"低价值内容"是**整站判定**，不是单页判定。审核员会随机抽样若干页面，任何一篇被判定为薄内容/模板化，整站即被拒。因此重申前的检查单位是"整站最弱的那 5 篇"，不是"最好的 5 篇"。

## 二、拒审归因（本仓库实测，非通用猜测）

| 触发点 | 实测证据 | 严重度 |
|---|---|---|
| 薄内容 | 53 篇指南中 19 篇正文 <400 词，最薄 279 词 | 高 |
| 模板化 | 53/53 篇同章节序列、同表格列名、同收尾句式；免责表述每千字 12.3 次 | 高 |
| 可索引资产少 | 仅 15 篇英文支柱页 + 5 篇中文页进索引，其余 38 篇 noindex | 中 |
| 占位文本 | 部分线上页面会渲染 "boundary has not yet been published" 类 fallback | 中 |
| 内容暴发 | 全部内容集中在 2026-07 至 09 三个月上线 | 低（观察项） |

> 不是原因（已排除）：缺必要页面（7 个合规页齐全）、缺导航、缺 about/contact、站点结构混乱、采集或伪原创。

## 三、重申前必须完成的 6 项（缺一不可）

| # | 动作 | 验收标准 |
|---|---|---|
| 1 | 全部可索引页正文 ≥600 词（建议 ≥800） | 逐篇 `wc -w` 核对，薄文要么扩写、要么合并、要么保持 noindex 且不出现在任何列表 |
| 2 | 模板去同质化：至少 3 种章节结构变体 + 每篇 1 个"具体处境"段落 | 随机抽 3 篇不同类目，章节序列不应完全一致 |
| 3 | 免责表述收敛到每篇 ≤4 条 | 与 `drafts/disclaimer-convergence-plan-2026-10-27.md` 处方对应执行 |
| 4 | 清除所有线上占位/未完成文案 | 全站检索 "has not yet been published"、TODO、coming soon 类文本（产品页除外且不得出现在内容页） |
| 5 | 消除重复内容层 | 旧 `.html` 走 301（部署层已配 `deploy/legacy-redirects.conf`）；确认生产只发布 `dist/` |
| 6 | 补 E-E-A-T 载体 | about 页含核验方法论（怎么核、多久复核、来源层级）；指南作者从匿名团队改为具名角色 |

## 四、提交前 12 项自查清单

```
□ 抽 5 篇最薄的可索引文章，正文均 ≥600 词
□ 抽 3 篇不同类目文章，章节结构不完全相同
□ 抽 1 篇统计"不决定/不保证/以官方为准"类表述 ≤4 条
□ 全站搜索占位文案 = 0 处
□ 7 个合规页可从页脚一键到达（privacy / terms / cookie / editorial / affiliate / about / contact）
□ about 页有"我们如何核验官方来源"段落
□ 每篇文章有明确的最后核验日期（可见）
□ sitemap 中无 noindex 页（当前 41 条 URL 与 noindex 已自洽，回归确认即可）
□ 生产环境旧 .html URL 返回 301（curl -I 抽查 3 条）
□ ads.txt 可访问且内容为 pub-3018617123550799
□ 站点有真实访问量（Search Console 有展示/点击数据更好，非硬性门槛）
□ 距离上次拒审 ≥2 周，且站点有实质变化（无变化重申必拒）
```

## 五、时间线建议

```
第 1 周：薄文处置（扩写 5 篇 / 合并 8 篇 / 其余维持 noindex 并移出列表）
第 2 周：模板变体 + 免责收敛（按 drafts 处方执行）
第 3 周：E-E-A-T 补齐（about 方法论 + 作者角色）+ 全站占位文案清理
第 4 周：观察 Search Console 重新抓取（确认旧 URL 已 deindex），然后提交
```

## 六、二次拒审的常见原因（按发生概率）

1. **改得不够"肉眼可见"**：只改 meta 和标题，正文没变 → 审核员看到的是同一批页面
2. **薄文只是被 noindex 藏起来**：AdSense 看的是站点整体，藏起来不等于解决
3. **申诉间隔太短**：两周内无实质变化就重申，等于重复同一份材料
4. **新增了新的薄页**：整改期一边补一边发新短文，永远追不上
5. **站点可用性问题**：审核期站点 5xx、证书错误、地区不可访问

## 七、过审后立刻要做的事（不要提前做）

- 广告位接入（当前 `BaseLayout` 有 `enableAds` 门控但未承接 script，需接线）
- EEA/英国流量必须配置 Google 认证 CMP，否则该地区不出广告或违规
- 广告只投放在 contentStatus 为 reviewed 且非 noindex 的页面（站内已有 `adsEligible` 字段，接线时消费它）
- 前两周盯 Policy Center，避免"广告过多/内容不足"的版位问题

## 八、与本站治理流程的衔接

本手册中的第 1–6 项都涉及 `src/` 改动，必须在同一个 planning-map 同步窗口内完成并过独立审计（见 `docs/planning-map/README.md`）。
不要分多次小改后各自提交审核——审核看的是提交时点的站点状态。
