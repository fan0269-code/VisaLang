## 1. 内容目标与存量处理

目标是让读者选对任务、找到有决定权的机构，并带走一份可执行的准备记录。先通过LP00观察真实读者怎样完成A1任务，再按实际失败点增强现有内容；已经达到标准的段落保留，不重写已通过审核的全文来制造工作量。Laya仅是待验证收益的可选自然语言入口；初步技术/对照验证LP01a可以与LP00同时启动，不必先证明手选不足。它不会自动验证来源，也不会替读者作资格判断；其完整内容资产及后续优化由LP01b汇总两类证据后决定，所有Laya内容工作均不是A1核心发布前置。

当前英文53篇＝15个支柱＋24个其他支持页＋14个9/22恢复支持页；中文5个支柱＋3个恢复支持页。17个恢复网址包含14EN＋3ZH，不应再重复计入。页面计数与生产上线分开；当前内容发布范围仍为15EN/5ZH支柱，14个EN广告白名单是未来启用的上限，不代表必须随核心站点开启。恢复支持页继续self-canonical、noindex、无广告、在sitemap外；本轮未授权扩索引。当前代码仍按联合候选部署，关闭模型/广告并独立发布的能力须由未来LP05a实际实现和验收，不能由本规划文字替代。

## 3. 读者任务链与全站承接

**A1主线：**文章直达或手选任务 → 明确申请地与必要阶段 → 查负责机关和要求 → 已有证书核查/考试选择 → 官方报名与报价 → 报名、考日、递交三类材料 → 时间假设 → 保存准备记录 → 最终受理核验。已有答案可直接阅读；已有证书、已报名等读者进入对应步骤，不强迫完整重走流程。练习与复盘按独立学习需求接入，不阻塞准备记录保存。

**B1内容线：**选择长期居留或入籍专题 → 进一步明确现有四个路径/未知情况 → 分开核查语言、知识和其他条件 → 找主管机关 → 比较具体考试 → 本地报名/预算 → 时间与材料工作表 → 按学习需求诊断/复测。B1仍不是Finder/Checklist的完整configured流程。A1与B1对应不同当前任务；前者完成或时间推进不证明后者需要深化。既有B1纠错与来源维护照常，新资产由B1自身需求、缺口与维护能力决定。

| 用户目的/表达 | 内容承接与澄清 | 工具边界 |
|---|---|---|
| 配偶团聚 family | A1路线及要求；已有证书由读者明确选择 | 德国已配置A1准备流程；不保证个案资格 |
| 长期居留或入籍 | B1专题先区分实际程序；模型合并标签仍需手选下一层 | verify-only；不能把A1清单替代B1材料工作表 |
| Ausbildung | 查具体培训/学校/接收方和相关官方程序 | 有限核验指引；不承诺已配置完整路线 |
| 护理 | 区分培训、大学学位、职业认可/执业，信息不足先澄清 | 使用现有参考内容和有权机构入口；不判认可结果 |
| 大学学习 | 查目标大学和具体项目；一般平台只作定位入口 | verify-only；不由模型判断项目接受哪种证明 |
| 明确其他目的 other（如短期旅游） | 说明本站范围，提供手选与相应核验出口 | 不把other当入境许可或无需证明结论 |
| 仅问考试等级、多个目的或不清楚 unclear | 手选、考试参考或澄清；不硬塞进移民路径 | 不自动生成“无需证明”或确定资格结论 |

正文只解释确有来源的内容。上述机构分工是选源规则，不是在本轮新增任何具体申请要求。

## 5. 每包如何生产与验收

流程：①LP00读者观察、已确认缺陷或LP01a初验范围中的文案/定义缺口 → ②权威分工与来源台账 → ③可使用资产草稿 → ④正文/工具/译文一致性 → ⑤实际页面与任务测试 → ⑥冻结范围并同步规划图、完成自动与视觉证据 → ⑦独立Auditor修正复核及Vault同步 → ⑧进入对应的另行授权发布批次。核心、模型、广告分别验收；独立审计和内容治理不因分支拆分而省略。

每项高风险新增或实质修改事实100%记录URL、检查日、责任方、段落定位、允许支持内容、边界和使用位置。通用国家概览不能证明某项目、地方、考点或个案的结果。无法确认价格、时间、豁免或接受结论时，写出具体询问对象、需要询问的问题和应保存的回答，不填估计值。核验日只有实际重读相关来源后才更新。

每包记录：LC ID、关联原T/C任务、主要URL、语言/地区、具体产品、事实版本、独有资产、最多三个下一步、关联工具/译文、实际实施者/独立复核者、核验日、复查触发、实现状态、发布状态、风险和证据。草稿/来源完成/本地验收/生产发布分别记录，不用一个“完成”覆盖所有门槛。

通用验收：标题问题在开头回答；边界明确；关键事实可追溯；产物可实际填写/练习/保存；下一步可到达；误判可改正；英文和中文引用相同事实版本但不混淆地区。只有任务和范围等价才配hreflang。无效链接、错误资格结论和版本不一致不能被平均评分抵消。

每两周根据实际产能选择最多三项优先问题；首轮每周1个复杂资产包或1–2个实质小更新只是估算，复核工作包含在内，并非发文配额。已有资产通过检查即可记录“检查通过、无正文变更”；把时间转给失败路径或来源缺口。真人研究未完成则明确用户收益未知，LP01a初验及已知事实错误维护可独立继续；不以无读者可测为理由编造成功或自动投入完整语料/优化。

## 6. 搜索、双语与索引策略

继续做静态可读的主答案、清晰任务标题、来源、内链和真实结构化数据。目的描述、模型结果和私人计划不生成可索引的参数页；不为每个意图改写组合制造着陆页。加入Laya本身不是排名优势；有用程度、可靠性和原创资产才是内容建设的衡量对象。[Google有用内容指引](https://developers.google.com/search/docs/fundamentals/creating-helpful-content)、[生成式内容指引](https://developers.google.com/search/docs/fundamentals/using-gen-ai-content)（沿用先前规划窗口2026-09-23查阅记录，本次未刷新核验日；不保证排名）。

中文优先补真实读者遇到的核心任务和失败恢复，以及中国场景确有依据的模块；模型采用/改选说明只在Laya分支维护。根据可触达的目标人群与实际证据选择优先任务，不机械翻译所有支持页。英文也必须明确地区；语言选择不写入申请地假设。其他语言暂缓。

17个恢复支持页按风险与实际线索分批复盘“独有用途、内容质量、相关入口、历史信号、维护能力”。有价值也不自动恢复索引：需要单独提出URL清单、内链/sitemap/canonical/hreflang/广告影响、来源和实际可得GSC证据，再经独立审核与范围决定。索引评估与保留网址是不同动作；没有搜索数据就如实标未知。

## 7. 维护、测量和扩展条件

拟议维护节奏：每周处理读者纠错和官方变化线索；每月扫一次来源到期及链接；可变费用/报名内容默认30天复查，制度/格式内容默认90天复查，来源声明的更早日期或变更事件优先。到期未读不能只刷新日期，关键事实过期时回到待核验动作。频率为资源规划，不是现有自动化，也不是来源有效期保证。
