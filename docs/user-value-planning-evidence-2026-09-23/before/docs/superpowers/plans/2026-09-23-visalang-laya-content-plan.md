# VisaLang 内容建设计划：从文章目录到可完成的准备任务

日期：2026-09-23。配套[全站建设规划](2026-09-23-visalang-laya-overall-plan.md)。本文为后续实施规划；所有LC包初始状态均为`pending`、发布为`not_deployed`。本轮只更新规划与记录，没有改文章正文、规则、Laya模型或广告。

## 1. 内容目标与存量处理

目标是让读者选对任务、找到有决定权的机构，并带走一份可执行的准备记录。Laya增加了自然语言入口，但不会自动验证来源，也不会替读者作资格判断。优先增强现有内容，按缺口修改；已经达到标准的段落保留，不重写已通过审核的全文来制造工作量。

当前英文53篇＝15个支柱＋24个其他支持页＋14个9/22恢复支持页；中文5个支柱＋3个恢复支持页。17个恢复网址包含14EN＋3ZH，不应再重复计入。页面计数与生产上线分开；当前发布策略仍为15EN/5ZH支柱，14个EN广告白名单。恢复支持页继续self-canonical、noindex、无广告、在sitemap外；本轮未授权扩索引。

| 资产群 | 本周期处理 | 不做的自动推断 |
|---|---|---|
| 15 EN／5 ZH支柱 | 按LC包核对任务、事实版本、工具衔接与可带走结果 | 支柱不代表所有当地规则和例外已覆盖 |
| 17恢复支持网址 | 保持独立任务与原网址，检查与支柱的分工、相关链接和恢复路径 | 恢复源码不等于可以索引、展示广告或已在公网正常 |
| 24其他EN支持页 | 按风险/来源到期维护，优先C07已有证书；其他国家保持有限范围 | 无GSC数据不等于无需求、无价值，也不自动删除 |
| 12分类页及参考考试目录 | 保持当前政策，确认检索用途与范围说明 | 目录有考试名称不等于完整服务路线 |

## 2. 加入Laya后新增的三类内容资产

| 资产 | 必备字段 | 维护边界 |
|---|---|---|
| 权威事实 | claim ID、事实、地区/产品/程序、source URL、责任机关、段落定位、checkedAt、可支持范围、边界、有效/复查触发、引用位置 | 官方法律/受理、考试主办方、当地考点、编辑建议分开；不得以模型输出作来源 |
| 意图语料 | sample ID、原句、语言、当前目的、排除目的、需澄清原因、难例类型、来源/同意依据、标注者、split与冻结版本 | 首期可用独立编写的合成情境；不默默保存访客输入，不把测试样本当真实需求或搜索量 |
| 目的到内容映射 | intent、用户显式阶段、内容入口、支持级别、下一步、失败回退、事实/规则版本、语言/地区 | 先由用户确认目的，再用确定映射；未配置路线不被模型标签升级成完整流程 |

标注意图与核验事实是两道不同工序。改变文章不会自动改变模型；调模型不会使文章事实自动通过。先写清“family和settlement差在哪里”“只问B1考试为什么需要澄清”，再写模型标签或帮助文案。

## 3. 读者任务链与全站承接

**A1主线：**确认目的与申请地 → 查负责机关和要求 → 已有证书核查/考试选择 → 官方报名与报价 → 报名、考日、递交三类材料 → 时间假设 → 练习与复盘 → 清单/日历保存 → 最终受理核验。

**B1内容线：**选择长期居留或入籍专题 → 进一步明确现有四个路径/未知情况 → 分开核查语言、知识和其他条件 → 找主管机关 → 比较具体考试 → 本地报名/预算 → 时间与材料工作表 → 诊断/复测。B1仍不是Finder/Checklist的完整configured流程。

| 用户目的/表达 | 内容承接与澄清 | 工具边界 |
|---|---|---|
| 配偶团聚 family | A1路线及要求；已有证书由读者明确选择 | 德国已配置A1准备流程；不保证个案资格 |
| 长期居留或入籍 | B1专题先区分实际程序；模型合并标签仍需手选下一层 | verify-only；不能把A1清单替代B1材料工作表 |
| Ausbildung | 查具体培训/学校/接收方和相关官方程序 | 有限核验指引；不承诺已配置完整路线 |
| 护理 | 区分培训、大学学位、职业认可/执业，信息不足先澄清 | 使用现有参考内容和有权机构入口；不判认可结果 |
| 大学学习 | 查目标大学和具体项目；一般平台只作定位入口 | verify-only；不由模型判断项目接受哪种证明 |
| 明确其他目的 other（如短期旅游） | 说明本站范围，提供手选与相应核验出口 | 不把other当入境许可或无需证明结论 |
| 仅问考试等级、多个目的或不清楚 unclear | 手选、考试参考或澄清；不硬塞进移民路径 | 不自动生成“无需证明”或确定资格结论 |

正文只解释确有来源的内容。上述机构分工是选源规则，不是在本轮新增任何具体申请要求。

## 5. 每包如何生产与验收

流程：①读者任务与当前页面缺口 → ②权威分工与来源台账 → ③可使用资产草稿 → ④正文/工具/译文一致性 → ⑤实际页面与任务测试 → ⑥独立Auditor修正复核 → ⑦规划图与Vault同步 → ⑧进入另行授权的发布批次。

每项高风险新增或实质修改事实100%记录URL、检查日、责任方、段落定位、允许支持内容、边界和使用位置。通用国家概览不能证明某项目、地方、考点或个案的结果。无法确认价格、时间、豁免或接受结论时，写出具体询问对象、需要询问的问题和应保存的回答，不填估计值。核验日只有实际重读相关来源后才更新。

每包记录：LC ID、关联原T/C任务、主要URL、语言/地区、具体产品、事实版本、独有资产、最多三个下一步、关联工具/译文、实际实施者/独立复核者、核验日、复查触发、实现状态、发布状态、风险和证据。草稿/来源完成/本地验收/生产发布分别记录，不用一个“完成”覆盖所有门槛。

通用验收：标题问题在开头回答；边界明确；关键事实可追溯；产物可实际填写/练习/保存；下一步可到达；误判可改正；英文和中文引用相同事实版本但不混淆地区。只有任务和范围等价才配hreflang。无效链接、错误资格结论和版本不一致不能被平均评分抵消。

首轮每周选择1个复杂资产包或1–2个实质小更新作为产能预算，复核工作包含在内；并非发文配额。若已有资产通过检查，该包记录“检查通过、无正文变更”，把时间转给失败路径或来源缺口。

## 6. 搜索、双语与索引策略

继续做静态可读的主答案、清晰任务标题、来源、内链和真实结构化数据。目的描述、模型结果和私人计划不生成可索引的参数页；不为每个意图改写组合制造着陆页。加入Laya本身不是排名优势；有用程度、可靠性和原创资产才是内容建设的衡量对象。[Google有用内容指引](https://developers.google.com/search/docs/fundamentals/creating-helpful-content)、[生成式内容指引](https://developers.google.com/search/docs/fundamentals/using-gen-ai-content)（2026-09-23查阅；不保证排名）。

中文优先补核心任务、采用/改选/失败恢复和中国场景确有依据的模块；不机械翻译所有支持页。英文也必须明确地区；语言选择不写入申请地假设。其他语言暂缓。

17个恢复支持页在W10逐页复盘“独有用途、内容质量、相关入口、历史信号、维护能力”。有价值也不自动恢复索引：需要单独提出URL清单、内链/sitemap/canonical/hreflang/广告影响、来源和实际可得GSC证据，再经独立审核与范围决定。索引评估与保留网址是不同动作；没有搜索数据就如实标未知。

## 7. 维护、测量和扩展条件

拟议维护节奏：每周处理读者纠错和官方变化线索；每月扫一次来源到期及链接；可变费用/报名内容默认30天复查，制度/格式内容默认90天复查，来源声明的更早日期或变更事件优先。到期未读不能只刷新日期，关键事实过期时回到待核验动作。频率为资源规划，不是现有自动化，也不是来源有效期保证。

上线前用固定任务脚本记录独立完成/需帮助/失败，按语言、目的和支持状态报告分子分母；拟议真实读者测试尚未执行。上线后只有获准且实际采集的数据才可做增长决策：GSC展现/点击与查询、已定义且真实发送的工具事件、纠错反馈、服务聚合指标。当前T27无传输，不可给出真实工具完成率；确认Laya建议不等于结果正确。

扩展一项新范围前同时满足：现有A1任务维护稳定、无未解决关键事实错误；明确需求证据；既有页面无法承接；完整官方来源链；独有可交付资产；维护角色与预算；相应语言/模型/规则评测。先试一个任务，不同时开多个国家、城市、考试品牌和新语言。B1完整工具规则如要增加，另立LP/任务，不在LC内容更新中顺带实施。

W9–12优先复查模型失败恢复、两种语言理解差异、17个恢复页与24个其他支持页的任务分工，再选择最多三项改进。若尚未部署，继续本地任务测试，保持线上指标未知；24小时/第7天观察从实际上线计时。
