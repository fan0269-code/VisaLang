## 3. 产品方向与三种方案

| 方案 | 内容与技术投入 | 结论 |
|---|---|---|
| A：维持当前目的建议，先达到上线门槛 | 明确标签、拒识与恢复文案；独立评测、Linux验证；复用现有文章 | **当前推荐**，承接已有实现 |
| B：目的确认后的内容导航 | 建立“目的→阶段→核验问题→责任机关→文章/工具”确定映射；验证对读者有实际帮助 | A通过后分批建设；先在现有页面加模块，不默认新增SEO页面 |
| C：通用聊天、自动资格判断或自动内容发布 | 另需生成/检索系统、时效与引用控制、范围和责任设计 | 不纳入本周期；Laya本身是非生成式结构化决策模型 |

推荐主流程：**直接手选目的，或主动提交短描述获得Laya建议 → 用户确认/改选 → 用户提供国家与必要阶段信息 → 确定性规则 → 已核验内容与下一步清单 → 有权机关作最终判断。**手选入口与文章直达始终存在；阅读和工具使用不以模型成功为前提。

Laya的职责仅为降低选错入口的概率，收益尚待验证。它不生成签证要求、不判定豁免、不选择广告、不决定证书接受、不自动填国家、不把B1这个词直接解释成永居或入籍。结果必须沿用已有支持范围；未支持的目的提供明确核验出口。用户点击“采用”不是模型正确性的标签。

## 5. 质量与资源门槛（拟议目标，全部待测）

### 5.1 先冻结评测，再改模型

本轮仅提出协议，没有创建语料或取得新结果。先统一6类目的＋unclear的标注规范；考试咨询、多个未定目的、否定/历史经历不能强行落入一个申请目的。内容缺口与模型误判分别记录。

- 开发集至少120条，用于修改方案；既有20/28/48条实验只作回归，不作盲测。
- 新独立保留集240条：EN/ZH各120；每种语言6类明确目的各15条，unclear 30条，共180明确＋60需澄清。另建120条困难集，EN/ZH各60，覆盖否定、当前/过去/未来、护理三分、单问等级、多目的、未覆盖国家、短期探亲、混合语言、长输入和操纵输出。
- 两名独立标注者先盲标再裁决分歧，记录实际身份/角色；不得把AI审阅写成真人研究。同源句、翻译和近似改写只进同一split。冻结哈希后，调参者不接触保留集答案；看过并用于修复的保留集转回归，新候选需新的独立保留集。
- 比较手选流程、当前Laya、有限规则对照、最多两个候选混合方案。v2规则44/48来自自构样本，只是实验线索，不能替换独立评测或直接上生产。

| 指标与分母 | 拟议上线门槛 |
|---|---|
| 240条7类准确率（清晰输入被拒识也算错） | 总体≥90%，每种语言≥90%；报告宏F1与混淆矩阵 |
| 具体建议精确率＝正确具体建议/全部具体建议 | 总体≥95%；每个具体目的≥90%，某类无建议视为未通过 |
| 明确输入覆盖率＝180条明确输入中给出具体建议的比例 | ≥85%；不能靠全部拒识提高精确率 |
| unclear召回率＝60条应澄清中正确拒识/澄清比例 | ≥95% |
| 困难集错误强分类＝应澄清却强选、或明确目的被选为另一个目的 / 120 | ≤2%；预先列出的关键安全回归零失败 |
| 交互边界 | 未确认零自动填写/导航/出结果；超时、busy、关闭模型、旧响应均可手选完成 |

所有指标必须报告整数分子/分母及95%置信区间；没有达到门槛不能用“用户会纠正”豁免。上述样本量是首轮筛查规模，单类样本仍小，点估计通过不能宣称真实访客90%准确。若采用confidence阈值，先加独立校准集；不能把未经校准的confidence当正确概率。

### 5.2 Linux与成本门槛

在拟部署架构、锁定依赖和权重上测冷启动峰值、热请求、长输入、并发拒绝、断线后推理、重启、真实推理探针与静态站并行访问。拟议目标：热请求端到端p95≤2秒、p99≤5秒；24小时持续运行无OOM、无持续内存增长；网站/代理/服务全部运行时峰值占物理内存≤75%。记录负载、样本数和硬件，12秒前端回退仍需独立验证。

若目标不达标，先定位加载峰值和驻留占用，再实验精度、加载方式或模型选择；任何变更均重跑质量与容量门槛。不假定量化接口可用，不承诺特定节省比例。每月≤100元必须按续费价格、税、IPv4、备份和必要流量合计核实；本轮没有选购或认定任何机型符合预算。

预算、模型质量与联合发布条件无法同时满足时，提交实测成本/效果对比，由Owner决定调整预算、技术方案或发布日期。保持现有联合发布决定，不自动改成无Laya/无广告先发布。

## 8. 成效、商业与扩展

北极星是读者正确找到适用核验入口并完成一个准备动作。使用独立给定的测试任务核对正确性；模型采用率、访问量和广告曝光不能替代任务正确完成。

先用5–8名可招募且同意参与的读者做探索性手选/辅助流程对照，记录任务正确完成、误入路径、恢复、耗时与理解反馈；这是拟议研究，尚未招募，不自动联系任何人。小样本仅发现问题，不能当转化提升证明。

上线后在已获准且实际可用的数据范围内观察：GSC页面/查询、按定义的工具完成代理指标、纠错问题、官方链接可用性、来源逾期数、服务错误/延迟/内存。T27只定义事件且当前无分析发送器；服务聚合指标也不等于用户路径数据。采集新增行为前单独核对批准和隐私说明，不存自由文本或身份。

广告保持现有14篇英文支柱白名单，工具、敏感核验与支持页不因Laya接入自动开广告；费用页仍无广告。广告收入与账户审批不列为内容完成标准。付费包、联盟、会员、邮件与新国家需要独立需求证据、真实交付能力和Owner范围决定。
