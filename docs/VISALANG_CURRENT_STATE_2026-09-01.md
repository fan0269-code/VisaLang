## 2. 可核查资产基线

- 五个具体规划工具和工具中心已经存在。
- `npm test`、`npm run build`、`npm run launch-check` 和部署/回滚脚本已经存在。

### 2.2 内容

- 53 篇英文指南均记录为 `sourceReviewStatus: reviewed`。

### 2.3 可信度与质量

- Authority-first 内容政策已经写入仓库规范。

- 多项历史内容、SEO、404、依赖与 UI 改动已有聚焦回归测试和独立复核记录。

### 2.4 商业与联系能力

- 广告和发现隔离逻辑存在，但 CMP、Auto Ads、CLS 和 AdSense 账号侧状态仍需要当前生产证据。
