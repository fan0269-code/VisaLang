## 4. 全站内容规划：按读者任务建设

核心读者路径：明确当前任务 → 找有决定权的机构 → 查已有证书或准确考试产品 → 核验所选考点和报价 → 分开报名/考试/递交材料 → 记录已确认日期与假设 → 保存准备记录 → 回到负责机关确认。允许从已有证书、已报名等阶段直接进入。

| 内容群/对应窗口 | 下一份具体产物 | 事实与维护边界 |
|---|---|---|
| 首页/路线/工具目录 W03/LC01 | 三层能力入口：完整准备流程、内容专题、官方核验起点 | 与1 configured/4 verify-only一致；中英不暗示全量覆盖 |
| A1要求与已有证书 W04/LC04 | 负责机关问询卡＋已有证书核验卡＋可保存下一步 | 官方法律/受理机关决定；中国材料不能跨地区泛化；C07状态需证据 |
| A1比较 W05/LC05 | 具体成人产品差异表＋所选考点待确认项 | 品牌不替代准确产品；当地报价不泛化 |
| A1报名预算 W06/LC06 | 付款前记录：产品、考点、币种、日期、姓名、退改与未确认项 | 复用本地费用记录；最早10/09复查2条费用事实及4条费用记录 |
| 材料/时间/保存 W07/LC07 | 三类材料、已确认/假设、复制/下载/恢复，未知项有出口 | 不收证件号或私人文件；T19真实日历导入单列 |
| 17恢复＋24其他参考 W17/LC12 | 41页处置台账：维护、补一个任务、继续暂缓；逐页理由和下一复查触发 | 不自动删页、301、升索引或开广告；无流量数据写unknown |
| A1训练 W13/LC08 | 仅一个有真实需求的诊断→练习→自查→陌生题复测任务 | 自制练习不得冒充官方题或评分保证 |
| B1 W14/LC09–11 | 按独立需求选一个长期居留/入籍任务深化 | 既有纠错继续；完整工具路线另立范围，不从A1自然推导 |
| 其他国家/新增语言 | 维护现有来源与出口；暂缓广泛扩张 | 需需求、官方权威链、独有资产、维护能力与授权 |

每页最低价值验收：标题对应一个明确问题；首段回答可回答的部分；官方权威与地区边界；至少一个读者能使用的表/记录/对照；一个清晰下一步；与相邻页的独有分工。无法确认的事实改为具体读者核验动作，不填虚构结论。上述标准用于逐页审核，不能机械给61页加同一模板来制造篇幅。
