# VisaLang 内容整改与 60 天实施计划

编制日期：2026-09-08。本文是根据公开网站审计形成的待执行方案。尚未取得网站源码、部署权限、Search Console 和统计后台；文中任务不代表已经修改线上站点。精确 URL 以主审计的页面清单为准，未核实的路径不作猜测。

## 1. 目标、范围与执行原则

第一阶段把德国 A1 配偶团聚这一条路线做完整：读者能够判断自己的问题属于哪种情况、找到适用的证明要求、选择考试、准备报名并安排时间。现有 38 篇可发现指南是待逐页处理的内容资产，不是需要清空的数量指标。B1 永居与入籍在事实核验完成前只呈现实际支持的范围。

整改以用户任务为单位：同一个问题没有必要反复换标题；不同阶段的任务不能因为关键词相近就机械合并。首页、路线页、工具和指南必须对同一事实给出一致解释。先改最有用的一条路线，再扩展语言和主题。

沿用既有技术栈。拿到源码后先查 README、AGENTS.md、依赖清单、路由、内容来源、构建与部署配置，确认真实架构。历史上使用过的技术不能替代本次源码核实。没有证据时，不指定框架迁移，不猜测内容目录，不直接修改构建产物。

首轮交付为可审查的开发分支、改动说明和可用预览。线上发布作为独立动作处理；本计划不授权自动替换已上线站点。没有源码时，可以完成内容改稿、规则数据草案与任务卡，但不能声称代码整改完成。

## 4. 十二项内容 Brief

以下优先改造已有对应页面。URL 由页面清单和源码匹配，保留健康旧 URL；只有确认任务应合并时才新增或选择承接页。

### C01 德国配偶团聚：我的情况是否需要 A1？

- 读者问题：我的申请类型、家庭身份与例外情形会怎样影响要求？
- 独有资产：条件分支表或简短判断流程；输出适用情况、依据、缺失信息和下一步。
- 大纲：先给适用范围；基础要求；影响结论的变量；例外分类；3 个明确标注为示例的情境；证明准备入口。
- 来源类型：德国官方法律文本、主管部门说明、对应使领馆清单。验收：每条分支有直接依据，未知情况不强行判断。维护：季度及政策变更时复核。

### C02 A1 证明怎么选：考试证书与提交要求

- 读者问题：考试名称、机构名称和证书名称有什么不同，我该核对哪一项？
- 独有资产：具体证书—考试形式—适用申请范围—来源对照表，避免把机构认可等同于所有产品均受理。
- 大纲：术语区分；具体考试清单；如何读证书名称；选择步骤；不确定情形；报名入口。
- 来源类型：主管部门受理说明与考试机构产品说明。验收：表格每行对应具体考试，不写未经证实的“全球通用”。维护：季度及考试产品调整时。

### C03 A1 报名前检查：证件、姓名、考点与支付

- 读者问题：提交报名之前，有哪些错误可以提前避免？
- 独有资产：可保存的检查表，“错误—可能影响—修正方式”原创示例。
- 大纲：报名资格；证件与姓名；考试产品与考点；费用和改期条件；提交后确认；纠错入口。
- 来源类型：选定机构报名规则与考点说明。验收：先迁入 booking mistakes、pre-booking checklist 中的独有内容，再依据搜索任务、GSC 与外链决定是否合并 URL；中文报名故障指南单独评估；documents 保留独有任务；不把考日材料混成报名必需项。维护：月度检查入口，规则变化时更新。

### C04 选定地区 A1 报名入口与流程

- 读者问题：我所在地区哪里能报名，官方入口在哪里，实际要经过哪些步骤？
- 独有资产：少量已核验考点记录与真实操作说明，展示覆盖地区、核验日期和官方入口。
- 大纲：覆盖范围；机构与考点区别；入口表；报名步骤；没有日期或名额时怎么办；联系模板。
- 来源类型：考试机构与考点官方页面。验收：不伪造实时余位；筛选确实改变结果；未知状态直说。维护：月度；无力维护就缩小地区数量。

### C05 A1 完整费用预算

- 读者问题：除报名费，还要为交通、住宿、材料或重考预留多少钱？
- 独有资产：指定考点、指定核验日期的报价示例与可调整分项预算。
- 大纲：费用构成；已核验报价；用户自填费用；重考情境；总额计算；哪些费用仍未确认。
- 来源类型：官方价目表、退款/重考规则；非官方旅行支出只作用户输入或明确估算。验收：币种、单位、日期齐全，缺失金额不默认为免费。维护：月度或价格变化时。

### C06 从目标递交日期倒排考试计划

- 读者问题：应该何时报名和考试，哪些等待时间需要自己确认？
- 独有资产：可复算时间表，分别标识用户输入、官方已知时间和规划缓冲；至少 3 个情境。
- 大纲：时间组成；如何填写；倒排结果；无可用考试日期时的调整；重考余量；提交前复核。
- 来源类型：具体机构报名/出分说明、适用受理清单。验收：日期逻辑正确，不承诺签证处理时长；过去日期和不可能安排有提示。维护：季度及周期变化时。

### C07 A1 证书新近性：哪些“有效期”不是同一回事？

- 读者问题：机构证书规则与申请机关是否接受较早证书，有什么区别？
- 独有资产：发证机构规则、受理机关要求、个案能力核验三层对照。
- 大纲：直接解释；三类规则；适用机构举例；如何核对自己的情况；保存确认记录；常见误读。
- 来源类型：考试机构证书说明和具体受理机关文件。验收：不使用一句“永不过期”回答所有情况；不能把某馆要求推广到全球。维护：季度及政策变化时。

### C08 A1 考试当天准备清单

- 读者问题：出发前和入场前分别需要检查什么？
- 独有资产：按时间顺序组织的可打印清单，保留机构范围和来源。
- 大纲：考前一天；出发前；到场后；允许/禁止物品；迟到或证件问题；考后事项。
- 来源类型：具体机构考试通知与考试规则。验收：与报名清单分工明确；不编造通用入场要求。维护：季度，规则变化时及时更新。

### C09 B1 永居与入籍：先分清申请路径

- 读者问题：我需要的语言证明属于哪种程序，能否直接套用另一程序的要求？
- 独有资产：分开的路径卡，列出适用对象、语言相关条件、尚需核对的其他条件与证据入口。
- 大纲：程序区分；各路径语言要求；可能影响规则的身份；证明形式；常见错误；下一步。
- 来源类型：各程序官方法律与主管部门说明。验收：不把 B1 当成申请成功的充分条件；未核验分支保持说明性状态。维护：季度及法规调整时。

### C10 具体 B1 考试如何比较？

- 读者问题：考试结构、模块和重考规则怎样影响我的选择？
- 独有资产：按具体考试名称排列的结构、考试形式、成绩/证书、重考对照表。
- 大纲：比较范围；结构差别；报名和重考；证书输出；按需求选择；官方样题入口。
- 来源类型：考试机构官方产品页与规则文件。验收：不以品牌替代具体考试，不编造“最容易”排行；与 C02 的 A1 范围分开。维护：季度及考试调整时。

### C11 B1 诊断到复习：按弱项分配时间

- 读者问题：我该先补什么，如何知道计划是否需要调整？
- 独有资产：官方样题用途说明、自评记录表、可调整学习安排。
- 大纲：选择诊断材料；记录结果；定位弱项；安排练习；周复盘；如何改变计划。
- 来源类型：官方考试结构、公开样题和评分说明。验收：说明自评不是官方成绩预测；合并 study/difficulty/mock 的空泛重复；不复制整套官方试题。维护：半年或考试变化时。

### C12 B1 写作与口语复盘示例

- 读者问题：我怎么从一次练习中找到具体可改进的地方？
- 独有资产：原创练习、修改前后对照、逐项解释和自评表。
- 大纲：任务目标；原创初稿/示范；按评价维度复盘；修改演示；第二次练习；局限。
- 来源类型：官方能力描述和公开评价标准，加本网站原创材料。验收：不冒充官方评分；听说读写只有各自具备独立训练资产才分成独立页。维护：半年及考试变化时。

## 5. 编辑门槛、规则数据与语言同步

每页必须先通过五项硬门槛：标题问题获得回答；关键事实有直接依据；范围、时间、金额边界明确；有可使用的结果；没有失效交互或未完成占位。随后用内部 100 分表复核：任务完成 30、证据准确 30、独有资产 20、页面分工 10、使用体验 10；建议达到 85 分且无关键事实错误。该分数不是 Google 标准，也不能自动触发删除。

关键事实应独立于文章段落登记。可用 JSON、YAML 或现有内容系统实现；字段形式随源码调整：

```json
{
  "claimId": "稳定且唯一的内部标识",
  "claimText": "经过核验的具体结论",
  "route": "适用申请路线",
  "jurisdiction": "适用国家、地区或受理机构",
  "examProduct": "适用的具体考试名称或空值",
  "conditions": ["成立条件"],
  "exceptions": ["已核实例外"],
  "sources": [{"url": "官方证据页", "locator": "章节或条款位置"}],
  "effectiveFrom": null,
  "sourceCheckedAt": null,
  "nextReviewAt": null,
  "reviewedBy": "真实核验者",
  "status": "draft",
  "version": 1,
  "usedBy": ["内容或工具内部标识"]
}
```

日期未知就保留空值，不能用抓取时间冒充政策生效时间。展示的核验者必须真实参与，AI 草稿不等于专家审核。来源链接可访问不代表内容未变，人工要重新核对相关条款。

中英文共享事实标识和规则版本，分别维护自然语言表达。关键事实修改时，把关联译文标为待复核；未同步时显示准确范围或暂时收起受影响结论，不继续展示相互矛盾的答案。只有真正等价页面互设 hreflang，各语言页面保持适用的规范网址。中文内容不要求逐字翻译，但不能删掉英文中的限制条件。

## 6. 五个工具的功能验收

公开审计已验证下列五个工具均能生成结果，因此首轮工作是提升结果价值与连续性，不能表述为“修复五个完全不能用的工具”。每个工具须登记输入、规则来源、支持范围、输出用途、数据是否离开设备，以及正常、异常、边界用例。没有预算计算器，不因本文费用内容规划就增加第六个工具。

| 工具与真实 URL | 已有证据与当前问题 | 后续验收 |
|---|---|---|
| Route Finder：[路线判断](https://visalang.org/tools/route-finder/) | 有国家、用途、申请地点、当前水平、证书、提交日期六项必填；结果偏泛化，进入 Checklist 后路线未预选 | 支持范围准确；缺信息与不支持情况有独立结果；只要求会影响判断的输入；把已确认路线、语言等安全上下文传到下一步；不把用户自由文本放进网址 |
| Checklist Generator：[清单](https://visalang.org/tools/checklist-generator/) | 可生成 3 个较大检查项；复制结果包含条文和 1/3 等总数，未保留逐项状态 | 拆成可完成的具体行动；已完成/未完成状态逐项可复制；打印保留路线、来源和日期；从 Route Finder 进入后上下文一致；重置有效 |
| Timeline Calculator：[时间规划](https://visalang.org/tools/timeline-calculator/) | 输入 2026-12-15、14+30+7 天得到 latest 2026-11-24、cautious 2026-10-25，本例算术正确 | 为两个结果明确解释各自扣除的时间与缓冲；验证过去日期、跨年、闰日、空值及负数；用户修改等待天数后结果同步；不把规划日期说成机构保证 |
| Exam Comparison：[考试比较](https://visalang.org/tools/exam-comparison/) | 6 行多使用共享核验文字，仅最后一行有独立官方链接，比较信息不足 | 每行对应具体产品和比较维度；结构、证书、报名/重考等差别有直接依据；每个关键结论就近链接来源；没有证据的维度明确未知；不排名“最容易” |
| Reminder Planner：[提醒规划](https://visalang.org/tools/email-reminders/) | 生成主题、日期、路线、来源和 ICS 按钮；页面明确没有邮件服务；ICS 下载和跨日历导入未验证 | 保持“日历提醒”真实承诺；验证下载文件、事件标题、日期/时区、来源；至少测试 Apple Calendar 或 Google Calendar 之一实际导入，另一个未测就明确说明；不新增邮件发送基础设施 |

公共门槛：手机端不横向溢出，键盘可操作，标签与错误信息清楚，返回修改不丢失必要状态。当前浏览器无法调整视口，本轮没有完成手机实机或移动视口验收；表中手机要求全部属于后续门槛。提醒文件测试必须真实执行下载和导入，不能因为按钮可见就判定成功。

## 7. 合并、迁移与回滚

逐页选择保留、重写、合并、暂缓索引或删除。先检查是否有独立任务、现有内部链接、可用搜索数据与外链，再决定。没有 Search Console 时不能把没有查到排名认定为没有价值。

合并顺序：保存原文；完成承接页；验证承接了旧页的有用信息；建立旧 URL 到新 URL 的映射；在预览验证；经发布流程上线；同步内部链接、sitemap、canonical 与语言映射。永久合并用合适的 301/308，目标应为最终有效页，避免链式跳转和统一跳首页。没有等价承接页且确无保留价值时才考虑真实 404/410。

`noindex` 只控制搜索收录，不增加内容价值；实施时页面须允许抓取，恢复正式内容后检查是否解除。canonical 用于重复或高度相似版本，不应将不同任务强行指向一页。无需因页面短就移除，也不应删除实用清单、中文本地化、联系和编辑政策等有真实用途的页面。

每批变更保留一个可恢复版本，以及页面处置表、规则版本、内容快照和配置改动。上线后若出现关键路径失效、错误资格结论、错误金额、批量非预期 404 或语言错误指向，立即回滚相应批次；普通短期排名波动不能单独触发全站回滚。优先保留未受影响的修复，恢复错误映射与受影响内容，记录事故原因后再发布。

## 8. 统计、维护与广告审核

若具备后台权限，先记录改动前 28 天 GSC 的页面、查询、点击、展示及索引状态；发布后按相同页面组观察，不把迁移后的旧 URL 点击下降误判为全站损失。样本过小时以任务完成和错误修复为主，不承诺第几天获得排名。

建议最小事件：`route_started`、`route_completed`、`unsupported_case_shown`、`tool_completed`、`checklist_copied`、`official_link_clicked`。属性只收集白名单枚举，如内容标识、工具标识、语言、步骤、预定义错误码。默认不收姓名、证件、签证详情、自由文本、用户填写的 URL 或原始表单值；跳转来源用预设目标标识，避免把含敏感参数的完整 URL 发给统计服务。事件是否启动应遵循站点实际适用的隐私和同意设置。

每月复核收费、报名入口与考点信息；每季度复核语言和证明规则，官方变更时提前处理；半年复核学习方法与原创练习。按真实来源核验更新日期，不用定时改日期制造新鲜感。每月优先处理用户失败任务、来源变化和失效链接，再决定新增主题。

广告审核只能在站点实际整改完成后评估提交。无内容、低价值、施工中、纯导航等页面不应展示 Google 广告；对复制或改写内容必须增加实际价值。不存在本文能保证的文章数量、字数、流量或通过日期。

## 9. 工时、职责与缩减范围

估算总工作量 120–180 人工小时，前提是沿用现有站点，主要修正内容、规则和现有交互，不建设实时考位数据库或完整教学平台。

| 工作包 | 估算 |
|---|---:|
| 页面处置、来源台账与规则整理 | 15–22 小时 |
| 8 项 A1 核心内容核验和改写 | 40–58 小时 |
| 模板、5 工具关键缺陷及必要交互 | 25–38 小时 |
| 选定中文页面同步和最多 4 项扩展资产 | 25–40 小时 |
| 迁移检查、用户测试与发布后复核 | 15–22 小时 |
| 合计 | 120–180 小时 |

60 天需要每周约 15–23 小时。若一位新手每周只能投入 10 小时，合理周期约 12–18 周。AI 可以整理资料、起草与辅助编码，但关键事实复核和使用验证不能计为零成本。

职责可由一人兼任，但要分开记录：编辑负责结论、范围与来源；开发负责功能和配置；最终复核者检查文章、工具与不同语言是否一致。不能填写不存在的法律或教学专家。

时间不足时按顺序缩减：先只覆盖一个可维护地区；暂停新语言；B1 保持已核实基础说明；C11/C12 后移；优先修复工具关键问题，不做视觉大改版。前 30 天最小交付保留 A1 判断、证书选择、报名清单、费用与时间，确保一条核心路径完整。不能通过删掉限制条件、省略来源核验或批量清空文章来赶工。

## 11. 官方依据与内部标准的边界

Google 明确关注读者能否完成目标，并没有偏好字数；为制造新鲜感而批量增删内容并不能达到该目的。本计划的 85 分、8 项核心资产、5 人测试和维护频率均为内部管理建议。[以人为本的内容](https://developers.google.com/search/docs/fundamentals/creating-helpful-content)

大量生产低新增价值内容并以操纵排名为主要目的，属于规模化内容滥用关注的行为；是否使用 AI 不是唯一判定条件。[搜索垃圾内容政策](https://developers.google.com/search/docs/essentials/spam-policies)

搜索技术变更应分别遵守具体用途：[noindex](https://developers.google.com/search/docs/crawling-indexing/block-indexing)、[重定向](https://developers.google.com/search/docs/crawling-indexing/301-redirects)、[迁移映射与无关重定向问题](https://developers.google.com/search/docs/crawling-indexing/site-move-with-url-changes)、[canonical](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls)、[多语言 hreflang](https://developers.google.com/search/docs/specialty/international/localized-versions)。

Google 广告对页面用途和内容新增价值有实际要求；本计划不能承诺整改后一定获批。[无出版内容或低价值内容页面](https://support.google.com/publisherpolicies/answer/11112688?hl=en)、[复制内容页面](https://support.google.com/publisherpolicies/answer/11190248?hl=en)
