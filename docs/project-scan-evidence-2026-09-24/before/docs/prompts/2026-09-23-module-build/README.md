# VisaLang 功能模块窗口提示词

这是可复制的执行提示词包，共 **17个功能窗口＋1个集成窗口＋1个独立审核窗口**。W编号只表示分工，不新增或改写LP/LC状态。先把 [W00](W00-integration.md) 整个text代码块发给集成窗口；拿到独立副本分配后，再把各模块完整代码块发到相应窗口。每个提示词都会要求读取 [共同约定](COMMON.md)，无需手动拼接多段。

**建议第一批只开 W00＋W01＋W02＋W08**。W01先准备研究，无真人保持未验证；W02可以直接做有限本地初验；W08先做独立运行/发布适配，本地通过不能代替目标机验证。W03/W04也能启动来源/支持范围核查，但按实际产能分批，不必同时开所有窗口。

先满足 [调度规划](../../superpowers/plans/2026-09-23-visalang-module-dispatch-plan.md) 的条件再派后续模块。没有前置证据时提示词会要求先写缺口，不能自行扩大范围。所有窗口都不得自行提交、推送或部署。
